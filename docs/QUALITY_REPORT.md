# Detailed quality report
Every CI run, including failure, produces a Markdown and JSON report from job-step conclusions and uploaded evidence. It includes PASS, PASS_WITH_ISSUES, PARTIAL, NOT_TESTED/BLOCKED and FAIL, plus before/after metrics from the previously passing run. Baseline APK bytes use the actual APK (97,601,715 bytes), not its compressed GitHub artifact. No threshold is invented for unmeasured active code or device performance. The aggregate gate still fails when any required platform job fails. A green gate is not certification of whole-repository mutation, leak freedom, device parity or production readiness.
